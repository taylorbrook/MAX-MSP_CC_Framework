## Critical Gaps

### 1. validate_patch() API Mismatch (MG-06, CL-04, CL-05)

**Root cause:** During Phase 18 cleanup, `validate_patch()` in `validation.py:84` had its `patch_dir` parameter removed, but two callers were not updated:
- `hooks.py:270` — `validate_patch(data, patch_dir=path.parent)`
- `test_integration_patches.py:66` — `validate_patch(patch_dict, db, patch_dir=patch_path.parent)`

**Impact:** Every call to `validate_file()` crashes with `TypeError: validate_patch() got an unexpected keyword argument 'patch_dir'`. This breaks:
- `/max-build` step 5 (critic validation loop)
- `/max-iterate` step 15 (post-edit validation)
- All integration patch tests (~20 tests)

**Fix:** Either restore `patch_dir` parameter to `validate_patch()` or remove the kwarg from the two callers.

### 2. performancepatchtest.maxpat Fixture Missing

3 tests reference `patches/performancepatchtest/generated/performancepatchtest.maxpat` but the file is absent from disk. Likely removed during Phase 18 artifact cleanup.

### 3. Phase 28 Empty

`28-verification-integration-cleanup` directory exists but contains no plans, summaries, or verification artifacts. Created to address integration cleanup but never executed.
