**Helper: `_make_control(box_id, maxclass, varname, longname=None, **extras)`**
Builds a live.* control box dict. Sets `id`, `maxclass`, `numinlets=1`, `numoutlets=2`, `outlettype=["", "float"]`, `parameter_enable=1`. Sets `varname` if provided. If `longname`, sets it inside `saved_attribute_attributes.valueof.parameter_longname`. Merges `**extras` onto the box dict.

**Helper: `_build_device(device_type, name, tmp_path, controls)`**
1. Mock `src.maxpat.project.auto_commit_patch`
2. Call `create_m4l_project(device_type, name, tmp_path)`
3. Read the resulting .maxpat from `project_dir / "generated" / f"{name}.maxpat"`
4. Append each control dict as `{"box": ctrl}` to `patch_dict["patcher"]["boxes"]`
5. Return `(patch_dict, project_dir, patch_path)`

**Helper: `_run_pipeline(patch_dict, patch_path, device_type, tmp_path)`**
1. Call `polish_m4l_device(patch_dict)` (mutates in-place)
2. Call `layout_m4l_presentation(patch_dict)` (mutates in-place)
3. Write `patch_dict` back to `patch_path` as JSON (CRITICAL: write_amxd reads from file, not dict)
4. Call `review_patch(patch_dict)` to get critic results
5. Mock `src.maxpat.m4l_export.auto_commit_patch`, call `write_amxd(patch_path, amxd_path, device_type)` where `amxd_path = patch_path.parent / f"{patch_path.stem}.amxd"`
6. Read amxd_bytes from amxd_path
7. Return `(critic_results, amxd_path, amxd_bytes)`

**Helper: `_assert_within_height(patch_dict)`**
Iterates all boxes in `patch_dict["patcher"]["boxes"]`. For each box with `presentation_rect` of length 4, asserts `y + h <= DEVICE_HEIGHT` where `y = rect[1]`, `h = rect[3]`.

**Helper: `_assert_valid_amxd(raw_bytes, device_type)`**
1. Assert `len(raw_bytes) > AMXD_HEADER_SIZE`
2. Assert `raw_bytes[0:4] == AMXD_MAGIC` (b"ampf")
3. Map device_type to expected type bytes: `{"audio_effect": AMXD_TYPE_AUDIO_EFFECT, "instrument": AMXD_TYPE_INSTRUMENT, "midi_effect": AMXD_TYPE_MIDI_EFFECT}`
4. Assert `raw_bytes[8:12] == expected_type_bytes`
5. Unpack JSON length from header: `struct.unpack_from("<I", raw_bytes, 28)[0]`
6. Assert `len(raw_bytes[AMXD_HEADER_SIZE:]) == json_len`
7. Parse JSON body: `json.loads(raw_bytes[AMXD_HEADER_SIZE:])`
8. Assert `"patcher" in parsed_data`

**Helper: `_assert_all_coords_int(patch_dict)`**
For each box with `presentation_rect`, asserts all 4 values are `int` (not float).
