    - upstream(box) returns list of all boxes reachable upstream (BFS, full chain to sources)
    - Results ordered by outlet index (left to right) for natural signal-flow reading
    - Starting box is NOT included in result list
    - downstream(box, signal_only=True) only follows connections where both source and dest box names end with ~
    - upstream(box, signal_only=True) same signal filtering
    - Traversal crosses subpatcher boundaries: when hitting a box with _inner_patcher, follow through inlet objects (for downstream) or outlet objects (for upstream) inside the subpatcher
    - Visited set prevents infinite loops in feedback patches
    - Empty result for boxes with no downstream/upstream connections
    - Raises ValueError if box not in this patcher
  </behavior>
  <action>
    1. Add a private `_build_adj(self, signal_only=False) -> tuple[dict, dict]` method to Patcher that builds forward and reverse adjacency dicts from self.lines:
    - forward[source_id] = list of (dest_id, source_outlet) tuples
    - reverse[dest_id] = list of (source_id, dest_inlet) tuples
    - If signal_only: skip connections where either source or dest box name does not end with "~"
    - Build a box_map {id: Box} for lookups
    - Sort each adjacency list by outlet/inlet index for left-to-right ordering

    2. Add downstream(self, box: Box, *, signal_only: bool = False) -> list[Box]:
    - Validate box in self.boxes
    - Build forward adjacency via _build_adj(signal_only)
    - BFS from box.id using deque, visited set, collect result list
    - For subpatcher crossing: when a downstream neighbor has _inner_patcher, find inlet objects inside (name "inlet" or "inlet~") whose argument matches the connection's dest_inlet index. Continue BFS from those inlet objects' connections within the inner patcher. When hitting an outlet/outlet~ object inside, map back to parent patcher's connections from the subpatcher box's corresponding outlet.
    - Use visited set of (patcher_identity, box_id) tuples to prevent infinite loops
    - Return result list (box objects, not IDs)

    3. Add upstream(self, box: Box, *, signal_only: bool = False) -> list[Box]:
    - Same as downstream but follows reverse adjacency
    - Subpatcher crossing: when an upstream neighbor has _inner_patcher, find outlet objects inside and trace backwards to their sources
