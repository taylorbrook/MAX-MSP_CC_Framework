- etc.

The cleanest approach: modify the extraction loop to track the source package alongside each object. In `discover_xml_files()`, the PACKAGE_GLOBS branch already knows the package directory. Pass the package name as a 4th tuple element for PACKAGE_GLOBS files:

Change `discover_xml_files()` return type to include package_name for package files:
