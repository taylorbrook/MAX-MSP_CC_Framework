Create `.claude/scripts/extract_abstractions.py` as a standalone Python script (stdlib only: json, pathlib, argparse, collections). The script handles both BEAP and Vizzie in a single unified pipeline per D-01.

**Constants:**
- `DEFAULT_MAX_PATH = Path("/Applications/Max.app/Contents/Resources/C74")`
- `BEAP_CLIPPINGS_REL = "packages/BEAP/clippings/BEAP"` (17 category subdirs)
- `BEAP_MISC_REL = "packages/BEAP/misc"` (standalone bp.* files + marco_osc/)
- `BEAP_HELP_REL = "packages/BEAP/Help"` (.maxhelp files for descriptions)
- `VIZZIE_PATCHERS_REL = "packages/Vizzie/patchers"` (vz.*.maxpat files)
- `INTERNAL_HELPERS = {"bp.freqshift.poly", "bp.polydronevoice", "bp.rgrain", "bp.diodeladder.poly"}` -- skip these (poly~/pfft subpatches, not user-facing)

**BEAP Clipping Extraction (Pattern 1 -- ~168 modules from clippings/BEAP/{Category}/):**
1. Iterate `clippings/BEAP/{Category}/bp.*.maxpat` files using `iterdir()` for categories and `glob("bp.*.maxpat")` for files.
2. Parse JSON. Find the embedded bpatcher box: `box["maxclass"] == "bpatcher"`.
3. Read `numinlets` and `numoutlets` from the bpatcher box.
4. Extract `patching_rect` from the bpatcher box -- use `[rect[2], rect[3]]` as `bpatcher_dimensions` (width, height).
5. Read inner patcher's boxes for inlet/outlet objects (`maxclass == "inlet"` or `maxclass == "outlet"`).
6. Sort inlets/outlets by `index` field (1-based in MAX). Convert to 0-based `id` values.
7. Extract `comment` field from each inlet/outlet for digest text.
8. Category = parent directory name (Oscillator, Filter, LFO, etc.) per D-03.
9. `abstraction_file` = relative path from BEAP package root: `"clippings/BEAP/{Category}/{filename}"`.
10. All BEAP I/O typed as `"signal"` with `signal: true` per BEAP 0-5V CV convention. `signal_convention: "0-5V CV"`.

**BEAP Misc Extraction (Pattern 2 -- ~20 standalone modules from misc/):**
1. Find `misc/bp.*.maxpat` and `misc/marco_osc/bp.*.maxpat` files.
2. Skip files in `INTERNAL_HELPERS` set.
3. Detect pattern: if file has an embedded bpatcher box, use Pattern 1 logic. If file has `in~ N`/`out~ N` text objects (marco_osc pattern), count those for signal I/O. If file has top-level `inlet`/`outlet` objects, count those.
4. Category = `"Misc"` for all misc modules.
5. `abstraction_file` = relative path from BEAP package root: `"misc/{filename}"` or `"misc/marco_osc/{filename}"`.

**BEAP Description Extraction from Help Patches (per D-02):**
1. For each extracted BEAP module, look for matching `.maxhelp` in `Help/` dir. Match by name: `bp.Oscillator` -> `bp.Oscillator.maxhelp`.
2. Parse help patch JSON. Search for comment boxes (`maxclass == "comment"`) in top-level patcher and first-level subpatchers.
3. Use the longest comment text as description/digest. Filter out instructional comments (starting with "try", "click", "Connect", "hover").
4. If no help patch found, use empty description.

**Vizzie Extraction (Pattern 3 -- ~110 modules from patchers/):**
1. Iterate `patchers/vz.*.maxpat` files directly (skip subdirectories like bfg/, gen/, launch/, utils/).
2. Parse JSON. Count top-level `inlet` and `outlet` objects (`maxclass == "inlet"` / `maxclass == "outlet"`).
3. Sort by `index` field (0-based for Vizzie), assign 0-based `id`.
4. Extract `comment` from each inlet/outlet for digest.
5. Description from `patcher.description` field (100% coverage per research).
6. Category from `patcher.tags` field -- extract the "Vizzie {Category}" part (e.g., "Vizzie Generate" -> "Generate") per D-03 + Pitfall 4.
7. `abstraction_file` = `"patchers/{filename}"`.
8. Vizzie I/O types: infer from `comment` text. Inlets with video/matrix/texture keywords -> `"matrix"`, `signal: false`. Others -> `"control"`, `signal: false`. `signal_convention: "Jitter matrix"`.
9. `bpatcher_dimensions` from top-level `patcher.default_bgcolor` ... actually from the Vizzie patcher's `rect` in `patcher.rect` or default `[0, 0, 300, 200]` if not present. Check for `patcher.rect` field.

**Output Format (per D-05, D-06, D-07):**
Each object entry keyed by name in the JSON dict:
```python
{
    "name": "bp.Oscillator",
    "maxclass": "bpatcher",         # D-05
    "module": "max",
    "domain": "Packages",
    "category": "Oscillator",        # D-03, D-06
    "digest": "Classic oscillator...",
    "description": "...",
    "inlets": [{"id": 0, "type": "signal", "signal": True, "hot": True, "digest": "CV1: ..."}],
    "outlets": [{"id": 0, "type": "signal", "signal": True, "digest": "Signal output"}],
    "arguments": [],
    "messages": [],
    "attributes": {},
    "seealso": [],
    "tags": ["BEAP", "Oscillator"],
    "min_version": 8,
    "verified": True,
    "variable_io": False,
    "rnbo_compatible": False,
    "package": "BEAP",               # CRITICAL for ObjectDatabase filtering
    "abstraction_file": "clippings/BEAP/Oscillator/bp.Oscillator.maxpat",  # D-06
    "bpatcher_dimensions": [314.0, 116.0],  # D-06
    "signal_convention": "0-5V CV"   # D-06
}
```
