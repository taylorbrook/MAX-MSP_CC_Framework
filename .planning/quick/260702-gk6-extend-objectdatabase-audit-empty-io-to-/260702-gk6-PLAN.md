<objective>
Extend `ObjectDatabase.audit_empty_io()` so it reports EVERY empty-I/O entry across all 8 domain sources, grouped by source package/module. Today the audit iterates the merged `self._objects` dict (one entry per canonical name), so the 121 package empty-I/O entries that share a name with a populated core-domain object are silently shadowed and never seen. The audit's three buckets sum to 43; the true raw total across all domain files is 164.

Purpose: The audit is the DB-health signal for "silent-failure time bombs" (objects that `lookup()` returns but the patch builder cannot connect). Missing 121 package entries defeats that signal — abclib, Bach, CNMAT, Jitter Tools, Mira etc. entries with empty I/O go unreported.

Output: An additive `by_source` view on `audit_empty_io()` whose grand total equals an independent brute-force count of empty-I/O entries across every domain file, plus a regression test locking that equality in.
</objective>
