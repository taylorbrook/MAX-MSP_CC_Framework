## Decisions Made
- GNU tar `--transform` for path prefix rewriting (ubuntu runners use GNU tar, not BSD)
- Zero external dependencies in the CLI script -- uses only Node.js stdlib (https, child_process, fs, path) for Node 16+ compatibility
- Manual HTTP redirect following (up to 5 redirects) instead of using fetch() which may not exist in Node 16
- Pipe HTTP response stream directly to tar stdin instead of writing a temp file to disk
- Clean up target directory on failure (rm -rf) to avoid leaving a half-extracted mess
- `.release-ignore` uses paths without trailing slashes for GNU tar compatibility
