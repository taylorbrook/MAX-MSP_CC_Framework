Signature:
```python
def replace_box_safe(
    self,
    old_box: Box,
    new_name: str,
    *,
    args: list[str] | None = None,
    rewire: str = "auto",
) -> EditResult:
```

Implementation strategy (delegate to existing replace_box to avoid duplication):

1. **Capture old box I/O counts BEFORE delegating** (because `replace_box` removes the old box):
   ```python
   old_numinlets = old_box.numinlets
   old_numoutlets = old_box.numoutlets
   ```
   (This must happen before the `replace_box` call — after removal, `old_box` is no longer in `self.boxes` and its attributes can no longer be safely correlated with the patcher.)

2. **Validate `rewire` argument:** accept only `"auto"` or `"manual"`. Raise `ValueError` with a clear message for any other value (mirrors the strict-input style elsewhere in the file).

3. **Delegate to existing `replace_box`:**
   ```python
   result = self.replace_box(old_box, new_name, args=args)
   ```
   This handles the not-in-patcher ValueError (re-raised naturally), captures orphans, removes the old box, and creates the new box at the old position. `result.box` is the new box; `result.orphaned` contains every old connection.

4. **If `rewire == "manual"`:** return `result` unchanged (same shape as existing `replace_box`).

5. **If `rewire == "auto"`:**
   - Compare I/O counts: `if result.box.numinlets == old_numinlets and result.box.numoutlets == old_numoutlets:`
   - **Match → auto-rewire:** for each orphaned dict, build an `add_connection` call. The orphaned dict uses the OLD box's id (since it was captured pre-removal). Map old box id to new box id when reconnecting:
     ```python
     for o in result.orphaned:
         # Resolve source: if old box was source, use new box; else look up by id in self.boxes
         if o["source_id"] == old_box.id:
             src_box = result.box
         else:
             src_box = next(b for b in self.boxes if b.id == o["source_id"])
         # Resolve dest: if old box was dest, use new box; else look up by id
         if o["dest_id"] == old_box.id:
             dst_box = result.box
         else:
             dst_box = next(b for b in self.boxes if b.id == o["dest_id"])
         self.add_connection(src_box, o["source_outlet"], dst_box, o["dest_inlet"])
     ```
     Then return `EditResult(box=result.box, orphaned=[])` so the caller observes zero orphans on success.
   - **Mismatch → fall back:** return `result` unchanged (orphans intact). Do NOT raise.

6. **Docstring:** include sections for purpose, args (old_box, new_name, args, rewire), returns (EditResult — empty orphaned on auto-rewire success, populated on manual or mismatch), raises (ValueError if old_box not in patcher OR if rewire is not "auto"/"manual"), and a brief note: "Mirrors P1-1 in 260427-hox FINDINGS. Use this in preference to replace_box for new code; replace_box is preserved for explicit orphan handling."

Edge cases the implementation must handle correctly:
- The same connection where old_box is BOTH source and dest (self-loop): both id-matches resolve to result.box. The mapping logic above handles this naturally.
- Empty `result.orphaned` (no connections to/from old box): the auto-rewire loop runs zero times; return EditResult with empty orphaned. Same outcome as manual mode in that case — fine.
- `args` is forwarded to `self.replace_box(... args=args)` exactly; do not transform.

Do NOT introduce any other public API changes. Do NOT modify `replace_box`, `EditResult`, `add_connection`, or any other method.
