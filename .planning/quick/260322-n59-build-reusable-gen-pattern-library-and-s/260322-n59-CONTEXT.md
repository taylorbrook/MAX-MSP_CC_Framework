# Quick Task 260322-n59: Build reusable gen~ pattern library and standardized UI presets - Context

**Gathered:** 2026-03-22
**Status:** Ready for planning

<domain>
## Task Boundary

Build a reusable gen~ object pattern library (.gendsp files) and standardized UI presets to improve patch generation effectiveness. Replace common anti-patterns (line~ message hacks, metro jitter, raw gain) with sample-accurate gen~ alternatives. Standardize dial/control appearance across all generated patches.

</domain>

<decisions>
## Implementation Decisions

### Pattern Storage Format
- **Decision:** .gendsp files in a patterns/ directory
- Standalone Gen~ patcher files that agents embed via gen~ objects referencing the file
- Testable independently in MAX
- Not GenExpr snippets in markdown, not Python API helpers

### Scope of Gen~ Patterns
- **All four original categories plus three additional:**
  1. Ramps & envelopes — smooth ramp (replaces line~), exponential curve, AR envelope, full ADSR
  2. Parameter smoothing — one-pole smoother, lag processor for zipper noise prevention
  3. Phasor-based timing — master phasor clock, subdivider, swing generator (replaces metro+counter)
  4. Gain safety — soft clipper, normalization, safe-multiply
  5. Audio recording to buffer — buffer record/playback patterns
  6. Essential DSP — reverb, delay, compression as reusable gen~ building blocks
  7. Randomization tools — random number generators, noise sources, and other obviously reusable gen snippets

### UI Preset Enforcement
- **Decision:** Reference doc + agent wiring
- Dial presets stored in .claude/skills/references/ markdown file
- Agents consult reference during generation
- No Patcher API changes or critic additions for now
- Style based on rhythmic-sampler dial patterns

### Claude's Discretion
- Specific .gendsp file naming convention and directory structure
- Which additional "obviously reusable" gen snippets beyond the user's list
- Exact dial preset values (derive from working rhythmic-sampler patterns)
- How agents discover and reference .gendsp files during generation

</decisions>

<specifics>
## Specific Ideas

- gen~ ramp/ADSR that's more effective than line~ or curve~ for audio signal shaping
- Dial settings and readouts consistent in the style of the rhythmic-sampler project
- Phasor-based time synchronization (gen~ phasor instead of metro) for sample-accurate timing
- Buffer recording patterns for audio capture
- Essential DSP building blocks: reverb, delay, compression
- Randomization: RNG, softmax, noise sources

</specifics>
