Research and document distribution strategies for this specific framework. The investigation must cover these areas:

**1. npx create-* scaffolding pattern (primary investigation)**
Investigate the `npx create-xxx` pattern (like create-react-app, create-next-app) where an npm package contains a bin script that scaffolds a project directory. Research:
- How to create an npm package with a `bin` entry that runs a setup script
- The script would: create project dir, clone/download framework files, set up `.claude/` directory structure, copy CLAUDE.md, set up `src/maxpat/` Python library, create `patches/` dir
- Whether the 7.4MB object database can be included in the npm package or needs separate download
- npm package size limits and best practices for packages with large static assets
- How to handle the Python dependency (the framework needs Python 3.10+ but is not a pip package)
- Example: `npx create-max-framework my-project` would scaffold a ready-to-use directory

**2. Alternative: degit / tiged pattern**
Investigate `npx degit taylorbrook/MAX-MSP_CC_Framework my-project` -- zero-config git scaffolding without full clone history. Document pros/cons vs custom npx package.

**3. Alternative: Claude Code native installation**
Research whether Claude Code has any native mechanism for installing/sharing skills and commands (e.g., a skills marketplace, shared skill repos, `claude install` command). Check Claude Code docs for any distribution features.

**4. Alternative: Shell script installer**
Simple `curl | bash` or downloadable shell script that does the setup. Compare to npx approach.

**5. Hybrid: npm package + Python package**
Whether `src/maxpat/` should also become a pip-installable package (pyproject.toml) so users get `pip install max-patcher` alongside the npx scaffolding.

**For each option, document:**
- Setup: what the user runs
- What it installs/creates and where
- How updates work (versioning, pulling new object database, etc.)
- Complexity to implement
- Gotchas (npm package size limits, Python dependency management, .claude/ directory requirements)

**6. Recommendation**
Based on the research, recommend the best approach considering:
- This framework's specific structure (Claude Code skills + Python source + large JSON database)
- Target audience (Claude Code users who do MAX/MSP, technical but want easy setup)
- Maintenance burden for the framework author
- Update story (new objects, new agents, bug fixes in Python code)

Write all findings to FINDINGS.md with clear sections, concrete examples of what package.json / bin scripts would look like, and a final recommendation with implementation steps.
