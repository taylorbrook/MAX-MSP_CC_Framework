  <action>
Add 8 new sub-functions to validation.py, each returning list[ValidationResult]. All use layer="domain".

The `_validate_domain_rules` function already builds `box_lookup` and connection structures. Add the 8 new calls after the existing `_check_feedback_loops` call. For checks 3 and 5 (which need connection info), also build a control adjacency map: `ctrl_adj: dict[str, list[str]]` mapping source box id to destination box ids for non-signal connections. Build this alongside the existing `signal_adj` in `_validate_domain_rules`.

**1. `_check_genexpr_io_syntax(box_lookup)`**
- Iterate box_lookup, find boxes where maxclass=="newobj" and text starts with "codebox"
- Get the "code" attribute from the box dict
- Scan code with `re.search(r'\b(in|out)\s+\d', code)`
- If match: error, "GenExpr codebox uses 'in1'/'out1' (no space), not 'in 1'/'out 1'"

**2. `_check_genexpr_delay_usage(box_lookup)`**
- Same codebox detection as check 1
- Scan code with `re.search(r'\bdelay\s*\(', code)`
- If match: error, "GenExpr uses Delay.read()/Delay.write(), not delay() function"

**3. `_check_gen_param_message_syntax(box_lookup, ctrl_adj)`**
- Find message boxes (maxclass=="message") whose text matches `re.search(r'@\w+\s+\$', text)`
- Check if any destination of this message box (via ctrl_adj) is a gen~ object
- If connected to gen~: warning, "gen~ params use plain name messages ('depth $1'), not '@depth $1'"
- If NOT connected to gen~: skip (@ syntax is valid for other objects)

**4. `_check_comment_hash_substitution(box_lookup)`**
- Find boxes with maxclass=="comment"
- Check text for `re.search(r'#\d+', text)`
- If match: warning, "Comment boxes don't support #N substitution; use loadbang -> message -> set chain"

**5. `_check_line_tilde_comma_messages(box_lookup, ctrl_adj)`**
- Find message boxes whose text contains "," (literal comma character)
- Check if any destination (via ctrl_adj) is a line~ object
- If connected to line~: warning, "line~ replaces ramps on new messages; use single list without comma separators"

**6. `_check_multislider_fetchindex(box_lookup)`**
- Find message boxes (maxclass=="message") whose text contains "fetchindex" (literal string match, case-sensitive)
- If found: error, "multislider uses 'fetch' not 'fetchindex'; fetchindex does not exist"

**7. `_check_umenu_items_format(box_lookup)`**
- Find boxes where maxclass=="umenu" or (maxclass=="newobj" and text starts with "umenu")
- Check for "items" attribute in box dict -- it should be an array
- If items is a list and has more than 1 element and "," not in items: warning, "umenu items need comma separators: ['LP', ',', 'HP', ',', 'BP']"

**8. `_check_assistance_comments(box_lookup)`**
- Find boxes where maxclass is "inlet" or "outlet"
- Check for "comment" attribute -- should be a non-empty string
- If missing or empty: info, "inlet/outlet missing assistance comment (tooltip)"
