# Quick 260924-8a6: "p about" subpatch for every patch

Add a `p about` subpatcher, modelled on `patches/looper/generated/looper.maxpat` (box `p about`, obj-57), to each
user-facing main patch. Looper already has one. Abstractions/bpatcher children, voices, test harnesses and demos
are out of scope (dbap-source, disintegrate-helper, gen-eq-*-test, slice-voice, mixer-strip/bus/master, comp-band,
psycography sub-modules, slot, sample-layers-slot, scala-synth-voice, terrain-* children, wormhole-test, looper-demo).

## Template (from looper)
- Parent box: `newobj` text `p about`, 0 in / 0 out, not in presentation, placed in empty top-right patching space.
- Inner patcher rect [120,120,750,H]; only `comment` boxes, x=20, width 700, Arial, no textcolor.
  - Title "NAME -- one-line purpose": fontsize 16, fontface 1, height 26, y=20.
  - Section header: fontsize 13, fontface 1, height 23; +10px gap before every header after the first.
  - Body line: fontsize 12, height 22, 22px pitch; one short sentence per line; continuation lines indented 4 spaces.
- Sections: USING IT (controls in user terms), optional INPUTS & OUTPUTS / AS A BPATCHER, HOW IT WORKS (2-5 lines).
  ~8-20 body lines total. Accurate to the current patch; never invent controls.
