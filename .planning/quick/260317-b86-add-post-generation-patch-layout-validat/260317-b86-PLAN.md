  <action>
    Create `src/maxpat/critics/layout_critic.py` with a single public function:

    ```python
    def review_layout(patch_dict: dict) -> list[CriticResult]
    ```

    The function performs three checks on the top-level patcher (not recursive into subpatchers -- subpatcher layout is their own concern):

    **Check 1: Overlapping boxes** -- For each pair of boxes, check if their patching_rects overlap (accounting for COLLISION_PAD=5.0px from Phase 15-02 decision). Skip comment and panel boxes (maxclass in {"comment", "panel"}) since they are decorative background elements. Use an O(n^2) sweep which is fine since MAX patches rarely exceed ~200 boxes. Report as warning severity with both box IDs and their text/maxclass.

    **Check 2: Missing cable midpoints** -- For each patchline, compute source outlet position (box x + width/2 or proportional for multi-outlet) and destination inlet position. If the horizontal distance exceeds HORIZONTAL_THRESHOLD (20px from defaults.py) AND the patchline has no midpoints, report a warning. Similarly, if the cable flows upward (source y > dest y) by more than UPWARD_BUS_THRESHOLD (60px) and has no midpoints, report a warning. Import threshold constants from src.maxpat.defaults.

    **Check 3: Out-of-bounds placement** -- Any box with patching_rect x < 0 or y < 0 is flagged as a warning (objects off the visible canvas).

    Helper functions:
    - `_rects_overlap(r1, r2, pad)` -- AABB collision with padding
    - `_outlet_x(box, outlet_idx)` -- approximate outlet x position (same logic as layout.py _outlet_x but working on raw dicts)
    - `_inlet_x(box, inlet_idx)` -- approximate inlet x position

    Then append tests to `tests/test_critics.py` in a new `TestLayoutCritic` class using the existing `_make_patch()` helper.
