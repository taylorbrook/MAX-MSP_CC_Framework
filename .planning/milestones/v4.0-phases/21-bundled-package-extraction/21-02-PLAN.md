**5. Modify write_output() to write per-package directories:**

After writing the domain-level files (existing behavior), add per-package writing:
```python
# Per-package output (only writes packages that have objects in this run)
pkg_buckets = result.get("package_buckets", {})
for pkg_name, objects in pkg_buckets.items():
    pkg_dir = output_root / "packages" / pkg_name
    pkg_dir.mkdir(parents=True, exist_ok=True)
    json_path = pkg_dir / "objects.json"
    sorted_objects = dict(sorted(objects.items()))
    json_path.write_text(
        json.dumps(sorted_objects, indent=2, ensure_ascii=False) + "\n"
    )
    print(f"  Wrote {len(objects)} objects to {json_path}")
```

**Overwrite protection:** The per-package write loop only iterates over `package_buckets` which only contains packages that had objects discovered in THIS extraction run. When running with `--domain packages`, the `discover_xml_files()` function only visits PACKAGE_GLOBS entries. Existing packages (ableton-dsp, Mira, jit.mo) WILL be re-extracted and re-written. This is acceptable because the XML pipeline is the authoritative source for these packages -- re-extraction produces identical output. The new per-package routing replaces the monolithic `packages/objects.json` approach.
