```python
class Patcher:
    db: ObjectDatabase
    boxes: list[Box]
    lines: list[Patchline]
    props: dict

    def connected_components(self) -> list[list[Box]]: ...
    def signal_path(self, box: Box) -> list[Box]: ...
    def downstream(self, box: Box, *, signal_only: bool = False) -> list[Box]: ...
    def upstream(self, box: Box, *, signal_only: bool = False) -> list[Box]: ...
    def find_boxes(self, *, id=None, name=None, maxclass=None, text=None, recursive=False) -> list[Box]: ...
    def _build_adj(self, signal_only: bool = False) -> tuple[dict, dict, dict]: ...
    # _build_adj returns (forward, reverse, box_map) where:
    #   forward[source_id] = sorted list of (dest_id, source_outlet) tuples
    #   reverse[dest_id] = sorted list of (source_id, dest_inlet) tuples
    #   box_map maps id -> Box

class Box:
    name: str          # Object name (e.g., "cycle~", "send~")
    args: list[str]    # Arguments (e.g., ["440"], ["live-input"])
    id: str            # Unique ID (e.g., "obj-1")
    maxclass: str      # MAX class (e.g., "newobj", "toggle", "comment")
    text: str          # Full text (e.g., "cycle~ 440")
    patching_rect: list[float]  # [x, y, w, h]
    extra_attrs: dict[str, Any]
    _inner_patcher: Patcher | None  # Subpatcher contents

class Patchline:
    source_id: str
    source_outlet: int
    dest_id: str
    dest_inlet: int
```

       - Total connections at top level: len(self.lines)
       - Max nesting depth: recursive walk of _inner_patcher (0 = no subpatchers)
       - Unique object names: len(set(b.name for b in self.boxes))

    3. **_analyze_signal_chains(self) -> str**:
       - Build signal-only adjacency via _build_adj(signal_only=True)
       - Find signal chain roots: ~ objects that have NO entries in the reverse adjacency dict (no signal-rate inputs). Also include receive~ / r~ objects as chain continuation points.
       - For each root, build a tree recursively (DFS): at each node, list all downstream signal neighbors as children. Track visited to avoid cycles.
       - Also integrate send~/receive~ pairs: when a send~ is reached, note it and show the continuation from the matching receive~ using "...-> receive~ name (wireless)" notation.
       - Render tree as indented text with "-> " arrows. Each fork shows branches indented.
       - Format under "## Signal Flow" header.
       - If no signal objects, return "## Signal Flow\n\n(no signal objects detected)".

    4. **_analyze_control_paths(self) -> str**: Find notable control origins:
       - loadbang objects: trace downstream (signal_only=False) to show initialization chain
       - notein / ctlin / midiin: trace downstream for MIDI routing
       - metro / counter: trace downstream for clock/sequencer paths
       - Keep concise: show origin -> first 3-5 downstream objects, then "..." if longer.
       - Format under "## Control Flow" header.
       - If no notable control origins, return "## Control Flow\n\n(no notable control sources detected)".

    5. **_analyze_hierarchy(self, depth=0) -> list[str]**: Walk self.boxes looking for _inner_patcher. For each, format an indented line with the subpatcher name (box.args[0] if available, else box.name) and inner object count. Recurse into inner patchers. Return list of lines. The public caller wraps with "## Subpatchers" header. If no subpatchers, "(none)".
