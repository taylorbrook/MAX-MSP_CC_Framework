# v0.12.0 manual test -- Chebyshev core

Open `terrain-synth.maxpat`, audio on. Console must stay clean at load (gen~ compile errors would name `terrain-cheby`).

1. **Regression:** with CHEBY A / B off everything sounds and looks as v0.11.0 (A > B MIX, orbit dials, MOTION, ANIMATE).
2. **CHEBY A on:** SHAPE A jumps to ellipse; TERRAIN A picture / 3D view show the polynomial; sound switches without a click.
   MIX at 0 so only A is heard.
3. **Presets:** saw / square / hollow xy / cross / glass / bell are audibly different; picture follows each.
4. **Radius = index:** RADIUS X / Y from 0.5 down to ~0.1 strips partials towards a sine; ROTATE and the XY pad re-voice it.
5. **BRIGHT:** 1.0 -> 0 darkens to the lowest-order terms, no zipper / clicks; picture redraws when the dial stops.
6. **Alias check:** saw preset, play the top two octaves and a slow pitch sweep (kslider drag): no inharmonic "birdies".
   Compare with CHEBY off on the same (now polynomial) terrain -- the table core should alias audibly up there.
7. **Limiter:** above ~C7 the tone thins to a near-sine, smoothly, no steps while gliding.
8. **CHEBY A off:** the previous terrain comes back (same noise roll; image source opens no dialog).
9. **Source change while CHEBY on:** pick another TERRAIN A source -> picture returns to the polynomial within a moment;
   CHEBY off then shows the newly chosen source.
10. **Slot B:** repeat 2-8 with CHEBY B, MIX at 1; B RATIO / DETUNE still apply. Both on: A and B presets are independent.
11. **Documented non-bandlimited cases** (expect aliasing, not a bug): squarcle, epitrochoid with non-integer LOBES,
    FEEDBACK != 0, heavy TERRAIN MOD, centre pushed so the orbit clips at the terrain edge.
12. **OVERSAMPLE 1x / 4x** (voices reload): mode survives the reload (tsyn-resend), sound unchanged.
13. **CPU:** note the meter with both slots in CHEBY, 8 voices held, 2x.
14. **Layout:** CHEBY CORE panel right of 3D VIEW: nothing clipped (menu text at 72 px, BRIGHT readout, wrapped 110 Hz note).
