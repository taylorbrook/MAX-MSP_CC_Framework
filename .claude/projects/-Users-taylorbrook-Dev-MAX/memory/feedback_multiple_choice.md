---
name: feedback_multiple_choice
description: Always present discussion/clarification questions in multiple-choice format, not open-ended
type: feedback
---

Always use multiple-choice format when presenting options or decisions to the user during kickoff, discussion, or any clarification phase.

**Why:** User prefers scanning and picking over reading paragraphs of explanation. Faster decisions, less friction.

**How to apply:** When presenting implementation choices, format each question with lettered options (a/b/c/d). Lead with the recommended option. Keep option descriptions to one line each. Add a brief rationale only on the recommended choice.
